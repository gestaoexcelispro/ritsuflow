# RitsuFlow Internationalization Terminology

RitsuFlow translations must preserve established Lean Construction and project-controls meaning. Product and methodology terms should not be translated literally when that would change their professional meaning.

Initial terms requiring controlled translation/review include:

- Master Plan
- Lookahead Planning
- Make Ready
- Weekly Work Plan / Weekly Planning
- PPC (Percent Plan Complete)
- Constraint / Constraint Management
- Work Package
- Production Cell
- Location Breakdown Structure
- Line of Balance
- Pull Planning
- PreCon
- FieldOp
- RitsuCAD

English (`en-US`) is the canonical source terminology. Portuguese (`pt-BR`) and Spanish (`es`) entries should be reviewed consistently as each functional area is migrated.
